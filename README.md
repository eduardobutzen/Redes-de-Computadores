### Unidade 1: TCP/IP

- Aplicar os conceitos e técnicas de TCP/IP para entendimento dos conceitos de vizinhança, de maneira precisa

- Aplicar os conhecimentos desenvolvidos para habilitar serviços em servidores Linux de maneira precisa.

- Compreender os diferentes métodos de roteamento dinâmico para gerenciar redes de grande porte de maneira adequada.
